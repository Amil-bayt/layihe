# 📝 To-do List Web App

Bu layihə HTML, CSS və JavaScript istifadə edilərək hazırlanmış sadə və funksional bir to-do list (tapşırıq siyahısı) tətbiqidir. İstifadəçilər tapşırıqları əlavə edə, silə və əlifba sırasına görə artan və azalan şəkildə sıralaya bilərlər.

## 🔍 Əsas Xüsusiyyətlər

- ✅ Tapşırıq əlavə etmə
- ❌ Tapşırıq silmə
- 🔤 Əlifba sırasına görə sıralama (artma və azalma)
- ✨ Hover effektləri ilə interaktiv ikonlar
- 🎨 Minimalist və modern dizayn

## 🛠️ İstifadə olunan texnologiyalar

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (Pure JS)**
